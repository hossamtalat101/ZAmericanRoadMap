# خطة تعلم اللغة الإنجليزية - ZAmericanEnglish

موقع ويب تفاعلي باللغة العربية لعرض خطة تعلم اللغة الإنجليزية لمدة 7 أشهر من ZAmericanEnglish.

## المميزات

- 📅 **خطة تعليمية شاملة**: 7 أشهر من التعلم من المستوى A1 إلى C1
- 📊 **تتبع التقدم**: نظام متقدم لتتبع تقدمك في كل مهارة
- 📱 **تصميم متجاوب**: يعمل على جميع الأجهزة (هواتف، أجهزة لوحية، حواسيب)
- 🎯 **نظام الإنجازات**: شارات وجوائز عند إكمال الأسبوع أو الشهر
- 🔔 **إشعارات يومية**: تذكيرات بالدروس اليومية
- 📈 **إحصائيات مفصلة**: رسوم بيانية توضح تطور مهاراتك

## البنية

```
├── index.html          # الصفحة الرئيسية
├── dashboard.html      # لوحة التحكم
├── weekly-plan.html    # الخطة الأسبوعية
├── statistics.html     # الإحصائيات
├── library.html        # المكتبة
├── settings.html       # الإعدادات
├── css/
│   ├── style.css       # الأنماط الرئيسية
│   └── responsive.css  # التصميم المتجاوب
└── js/
    ├── data.js         # بيانات خطة التعلم
    ├── progress.js     # نظام التتبع والتقدم
    ├── app.js          # المنطق الرئيسي
    ├── dashboard.js    # منطق لوحة التحكم
    ├── weekly-plan.js  # منطق الخطة الأسبوعية
    ├── statistics.js   # منطق الإحصائيات
    ├── calendar.js     # التقويم التفاعلي
    └── notifications.js # نظام الإشعارات
```

## الاستخدام

1. افتح `index.html` في المتصفح
2. اضغط على "ابدأ الرحلة التعليمية"
3. ابدأ في تحديد الدروس المكتملة
4. تتبع تقدمك في صفحة الإحصائيات

## التخزين

جميع بيانات التقدم تُحفظ محلياً في LocalStorage، لذا لا حاجة لخادم.

## المتطلبات

- متصفح حديث يدعم ES6+
- اتصال بالإنترنت (لتحميل الخطوط والأيقونات)
